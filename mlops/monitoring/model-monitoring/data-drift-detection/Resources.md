# Resources

## Tools and Libraries

- [Evidently AI](https://www.evidentlyai.com/) - Open-source ML monitoring and data drift detection
- [NannyML](https://www.nannyml.com/) - Performance estimation and data drift detection without ground truth
- [Alibi Detect](https://docs.seldon.io/projects/alibi-detect/en/stable/) - Outlier, adversarial, and drift detection library
- [Great Expectations](https://greatexpectations.io/) - Data validation and quality framework
- [WhyLabs / whylogs](https://whylabs.ai/) - Data logging, profiling, and monitoring platform
