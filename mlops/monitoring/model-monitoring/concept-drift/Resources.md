# Resources

## References Used

- [Evidently AI - Concept Drift in Machine Learning](https://www.evidentlyai.com/ml-in-production/concept-drift) - Comprehensive overview of concept drift types, detection, and handling strategies with real-world examples from Spotify, Instacart, and DoorDash.
- [DataCamp - Understanding Data Drift and Model Drift](https://www.datacamp.com/tutorial/understanding-data-drift-model-drift) - Tutorial covering the distinction between data drift and model drift, with coverage of DDM, EDDM, ADWIN, and Page-Hinkley detection methods.

## Foundational Papers

- Gama, J., Medas, P., Castillo, G., & Rodrigues, P. (2004). Learning with Drift Detection. SBIA 2004. - Introduces the Drift Detection Method (DDM).
- Baena-Garcia, M., del Campo-Avila, J., Fidalgo, R., Bifet, A., Gavalda, R., & Morales-Bueno, R. (2006). Early Drift Detection Method. - Introduces EDDM as an improvement on DDM for gradual drifts.
- Bifet, A. & Gavalda, R. (2007). Learning from Time-Changing Data with Adaptive Windowing. SDM 2007. - Introduces the ADWIN algorithm.

## Libraries and Tools

- [River](https://riverml.xyz/) - Python library for online machine learning with integrated drift detection (DDM, ADWIN, Page-Hinkley, EDDM).
- [Evidently AI](https://www.evidentlyai.com/) - Open-source ML monitoring with drift detection, performance reports, and dashboards.
- [Alibi Detect](https://github.com/SeldonIO/alibi-detect) - Library for outlier, adversarial, and drift detection.
