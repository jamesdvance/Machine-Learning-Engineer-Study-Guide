# DQN Resources

## Foundational Papers

- [Playing Atari with Deep Reinforcement Learning (Mnih et al., 2013)](https://arxiv.org/abs/1312.5602) - Original DQN paper introducing experience replay with a deep Q-network.
- [Human-level control through deep reinforcement learning (Mnih et al., 2015)](https://www.nature.com/articles/nature14236) - The Nature paper that added the target network and demonstrated human-level Atari performance.
- [Deep Reinforcement Learning with Double Q-learning (van Hasselt et al., 2016)](https://arxiv.org/abs/1509.06461) - Double DQN, addressing overestimation bias.
- [Dueling Network Architectures for Deep Reinforcement Learning (Wang et al., 2016)](https://arxiv.org/abs/1511.06581) - Dueling DQN architecture with value and advantage streams.
- [Prioritized Experience Replay (Schaul et al., 2016)](https://arxiv.org/abs/1511.05952) - Prioritized sampling from the replay buffer.
- [Rainbow: Combining Improvements in Deep Reinforcement Learning (Hessel et al., 2018)](https://arxiv.org/abs/1710.02298) - Combines six DQN extensions into one agent.

## Tutorials and Guides

- [PyTorch DQN Tutorial](https://pytorch.org/tutorials/intermediate/reinforcement_q_learning.html) - Official PyTorch tutorial implementing DQN for CartPole.
- [Hugging Face Deep RL Course - Q-Learning](https://huggingface.co/learn/deep-rl-course/unit3/introduction) - Interactive course covering DQN with code examples.
- [CleanRL DQN Implementation](https://github.com/vwxyzjn/cleanrl/blob/master/cleanrl/dqn.py) - Single-file, well-documented DQN implementation.

## Reference Implementations

- [Stable Baselines3 DQN](https://stable-baselines3.readthedocs.io/en/master/modules/dqn.html) - Production-quality DQN with documentation and benchmarks.
- [OpenAI Baselines](https://github.com/openai/baselines) - Reference implementations of DQN and its variants.
