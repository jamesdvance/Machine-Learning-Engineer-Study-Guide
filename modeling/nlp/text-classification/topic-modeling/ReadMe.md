# Topic Modeling

## Summary

Topic modeling is an unsupervised technique for discovering abstract topics within a collection of documents. Unlike supervised classification where labels are predefined, topic modeling automatically uncovers thematic structures from text. Each topic is represented as a distribution over words, and each document is represented as a mixture of topics.

Key points to remember:

- Unsupervised: No labeled data required; topics emerge from data patterns
- Generative models: LDA, NMF assume documents are mixtures of topics
- Embedding-based: BERTopic uses neural embeddings for semantic topic discovery
- Output: Topic-word distributions and document-topic distributions
- Number of topics (k) must be specified or determined automatically
- Topics require human interpretation; model outputs word distributions, not labels
- Coherence metrics help evaluate topic quality
- Applications: Document clustering, content recommendation, trend analysis

## Classical Methods

### Latent Dirichlet Allocation (LDA)

LDA is a generative probabilistic model that assumes:
1. Each document is a mixture of topics
2. Each topic is a mixture of words
3. Documents are generated by sampling topics, then sampling words from topics

```python
from sklearn.decomposition import LatentDirichletAllocation
from sklearn.feature_extraction.text import CountVectorizer

# Prepare document-term matrix
vectorizer = CountVectorizer(
    max_df=0.95,      # Ignore terms in >95% of documents
    min_df=2,         # Ignore terms in <2 documents
    max_features=5000,
    stop_words='english'
)
doc_term_matrix = vectorizer.fit_transform(documents)

# Fit LDA
n_topics = 10
lda = LatentDirichletAllocation(
    n_components=n_topics,
    learning_method='online',
    random_state=42,
    max_iter=50
)
lda.fit(doc_term_matrix)

# Get top words per topic
feature_names = vectorizer.get_feature_names_out()

def display_topics(model, feature_names, n_top_words=10):
    for topic_idx, topic in enumerate(model.components_):
        top_words_idx = topic.argsort()[:-n_top_words - 1:-1]
        top_words = [feature_names[i] for i in top_words_idx]
        print(f"Topic {topic_idx}: {', '.join(top_words)}")

display_topics(lda, feature_names)
```

### Gensim LDA

More control and better scaling:

```python
import gensim
from gensim import corpora
from gensim.models import LdaMulticore

# Prepare corpus
texts = [doc.lower().split() for doc in documents]

# Create dictionary and corpus
dictionary = corpora.Dictionary(texts)
dictionary.filter_extremes(no_below=5, no_above=0.5)
corpus = [dictionary.doc2bow(text) for text in texts]

# Train LDA
lda_model = LdaMulticore(
    corpus=corpus,
    id2word=dictionary,
    num_topics=10,
    workers=4,
    passes=10,
    per_word_topics=True
)

# View topics
for idx, topic in lda_model.print_topics(-1):
    print(f"Topic {idx}: {topic}")

# Get topic distribution for a document
doc_topics = lda_model.get_document_topics(corpus[0])
```

### Non-negative Matrix Factorization (NMF)

Factorizes document-term matrix into non-negative factors:

```python
from sklearn.decomposition import NMF
from sklearn.feature_extraction.text import TfidfVectorizer

# Use TF-IDF for NMF
vectorizer = TfidfVectorizer(
    max_df=0.95,
    min_df=2,
    max_features=5000,
    stop_words='english'
)
tfidf_matrix = vectorizer.fit_transform(documents)

# Fit NMF
nmf = NMF(
    n_components=10,
    init='nndsvd',
    random_state=42,
    max_iter=500
)
W = nmf.fit_transform(tfidf_matrix)  # Document-topic matrix
H = nmf.components_                    # Topic-word matrix

# Display topics
feature_names = vectorizer.get_feature_names_out()
display_topics(nmf, feature_names)
```

### LDA vs NMF

| Aspect | LDA | NMF |
|--------|-----|-----|
| Approach | Probabilistic generative | Matrix factorization |
| Input | Count matrix | TF-IDF (usually) |
| Interpretability | Topics as probability distributions | Topics as weighted term lists |
| Speed | Slower | Faster |
| Coherence | Often higher | Often lower |
| Online learning | Supported | Limited |

## Choosing Number of Topics

### Coherence Score

Measures semantic similarity of top words in each topic:

```python
from gensim.models.coherencemodel import CoherenceModel

def find_optimal_topics(corpus, dictionary, texts, start=5, end=30, step=5):
    """Find optimal number of topics using coherence."""
    coherence_scores = []

    for n_topics in range(start, end + 1, step):
        model = gensim.models.LdaMulticore(
            corpus=corpus,
            id2word=dictionary,
            num_topics=n_topics,
            passes=10,
            workers=4
        )

        coherence_model = CoherenceModel(
            model=model,
            texts=texts,
            dictionary=dictionary,
            coherence='c_v'  # 'u_mass', 'c_v', 'c_uci', 'c_npmi'
        )

        coherence = coherence_model.get_coherence()
        coherence_scores.append((n_topics, coherence))
        print(f"Topics: {n_topics}, Coherence: {coherence:.4f}")

    return coherence_scores

# Plot coherence vs number of topics
import matplotlib.pyplot as plt

scores = find_optimal_topics(corpus, dictionary, texts)
x, y = zip(*scores)
plt.plot(x, y)
plt.xlabel('Number of Topics')
plt.ylabel('Coherence Score')
plt.show()
```

## Topic Evaluation

### Coherence Metrics

| Metric | Description | Range |
|--------|-------------|-------|
| C_v | Sliding window, normalized PMI | 0 to 1 (higher better) |
| C_uci | Pointwise mutual information | -14 to 14 (higher better) |
| C_npmi | Normalized PMI | -1 to 1 (higher better) |
| U_mass | Log conditional probability | Negative (closer to 0 better) |

### Topic Diversity

Measures uniqueness of topics:

```python
def topic_diversity(topics, top_n=10):
    """Calculate topic diversity (unique words / total words)."""
    all_words = []
    for topic in topics:
        top_words = [word for word, _ in topic[:top_n]]
        all_words.extend(top_words)

    unique_words = set(all_words)
    return len(unique_words) / len(all_words)
```

### Human Evaluation

Intrinsic metrics don't always correlate with human judgment:

- Word intrusion: Insert random word; humans identify intruder
- Topic intrusion: Assign wrong topic; humans identify error
- Topic labeling: Humans assign labels; consistency measured

## Preprocessing for Topic Models

```python
import re
import spacy
from gensim.utils import simple_preprocess
from gensim.models.phrases import Phrases, Phraser

nlp = spacy.load('en_core_web_sm', disable=['parser', 'ner'])

def preprocess_for_topics(documents):
    """Preprocess documents for topic modeling."""

    # Tokenize and clean
    def clean_text(text):
        # Remove emails
        text = re.sub(r'\S+@\S+', '', text)
        # Remove URLs
        text = re.sub(r'http\S+', '', text)
        # Remove special characters
        text = re.sub(r'[^a-zA-Z\s]', '', text)
        return text.lower()

    cleaned = [clean_text(doc) for doc in documents]

    # Tokenize
    tokenized = [simple_preprocess(doc, deacc=True) for doc in cleaned]

    # Remove stopwords and lemmatize
    def lemmatize(tokens):
        doc = nlp(' '.join(tokens))
        return [token.lemma_ for token in doc
                if not token.is_stop and len(token.lemma_) > 2]

    lemmatized = [lemmatize(tokens) for tokens in tokenized]

    # Build bigram model
    bigram = Phrases(lemmatized, min_count=5, threshold=100)
    bigram_mod = Phraser(bigram)

    # Add bigrams
    with_bigrams = [bigram_mod[doc] for doc in lemmatized]

    return with_bigrams
```

### Content Recommendation

```python
def recommend_similar_documents(doc_id, topic_model, documents, n=5):
    """Recommend documents with similar topic distribution."""
    # Get topic distribution for query document
    query_probs = topic_model.approximate_distribution(
        [documents[doc_id]]
    )[0]

    # Get distributions for all documents
    all_probs = topic_model.approximate_distribution(documents)

    # Compute similarities
    from sklearn.metrics.pairwise import cosine_similarity
    similarities = cosine_similarity([query_probs], all_probs)[0]

    # Get top-n (excluding self)
    similarities[doc_id] = -1
    top_indices = similarities.argsort()[-n:][::-1]

    return [(idx, documents[idx], similarities[idx]) for idx in top_indices]
```

### Trend Analysis

```python
def analyze_topic_trends(documents, timestamps, topic_model):
    """Analyze how topics trend over time."""
    topics_over_time = topic_model.topics_over_time(
        documents,
        timestamps,
        nr_bins=12,  # Monthly for a year
        evolution_tuning=True
    )

    # Calculate growth rate per topic
    for topic in topics_over_time['Topic'].unique():
        topic_data = topics_over_time[topics_over_time['Topic'] == topic]
        early_freq = topic_data.head(3)['Frequency'].mean()
        late_freq = topic_data.tail(3)['Frequency'].mean()
        growth = (late_freq - early_freq) / early_freq if early_freq > 0 else 0
        print(f"Topic {topic}: {growth:.1%} growth")

    return topics_over_time
```

## Best Practices

1. Preprocess thoroughly: Remove noise, lemmatize, handle bigrams/trigrams

2. Experiment with number of topics: Use coherence scores but validate with domain knowledge

3. Iterate on topic quality: Adjust preprocessing, n_topics, and hyperparameters based on output

4. Label topics manually: Automatic word lists need human interpretation

5. Consider domain: Technical documents may need different preprocessing than social media

6. Use embeddings for short texts: BERTopic and Top2Vec work better than LDA on short documents

7. Validate with held-out data: Ensure topics generalize beyond training documents

8. Combine approaches: Use unsupervised topics as features for supervised classification
